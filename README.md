# Day 1 Task - Foundations of AI Agents

## Task Title

**Comparing a Plain Chatbot, a Rule-Based Workflow, and an AI Agent on a Scenario of Your Own**

## About the Task

This project is part of **Unit 1: Foundations of AI Agents**.

The purpose of this task is to compare three approaches to solving the same private-data problem:

1. Plain Chatbot
2. Rule-Based Workflow
3. AI Agent

The task demonstrates how each approach works, what data and tools it requires, how it handles a user's request, and where its limitations appear.

The key concept of the task is:

**Agent = LLM + Tools + Loop**

An AI agent can reason about a task, select appropriate tools, observe the results, and continue taking actions until the task is completed.
